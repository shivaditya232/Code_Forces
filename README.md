# Codeforces Solutions

My solutions to Codeforces problems, written in Java and C++ while practising competitive programming.

**89 problems solved** — 45 in Java, 44 in C++.

## Layout

Each problem lives in its own folder, named `Problem_name_ProblemID_Rating`:

```
Watermelon_4A_800/
Add_and_divide_1485A_1000/
Check_the_String_960A_1200/
```

The folder name carries the Codeforces problem ID, so `1485A` maps to
[codeforces.com/problemset/problem/1485/A](https://codeforces.com/problemset/problem/1485/A).

## Topics

Mostly implementation and simulation, greedy, elementary maths and number theory, strings, sorting and array manipulation — the usual Div. 2 A/B range.
